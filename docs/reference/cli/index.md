# CLI reference

`json-bench` runs experiments without Yanex. Each command has a `--help` option.
Use the [CLI guide](../../cli.md) for the full workflow.

| Command | Purpose |
| --- | --- |
| [prepare](prepare.md) | Generate data and prepare one database pair per scale factor |
| [benchmark](benchmark.md) | Execute combinations sequentially |
| [plot](plot.md) | Save PNG and PDF figures from completed results |
| [cleanup](cleanup.md) | Remove deployments and data after confirmation |
