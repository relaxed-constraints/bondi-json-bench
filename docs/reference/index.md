# API reference

Use these functions when extending the benchmark or writing Python experiments.
For normal benchmark runs, start with the [CLI guide](../cli.md).

| Module | Public interface |
| --- | --- |
| [Data](data.md) | Generate travel documents |
| [Queries](queries.md) | Load and translate templates |
| [Validation](validation.md) | Compare grouped results |
| [Preparation](preparation.md) | Create indexes and configure Couchbase |
| [Experiments](experiments.md) | Prepare deployments and run benchmarks |
| [Analysis](analysis.md) | Calculate summaries and assemble cohorts |
| [Plotting](plotting.md) | Build figures without displaying or saving them |

The API pages show signatures and docstrings from the implementation. Private
helpers are not part of the supported interface.
