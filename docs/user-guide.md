# User guide

Choose the workflow that fits your task.

| Workflow | Use it for |
| --- | --- |
| [CLI](cli.md) | Run one combination or a full matrix, resume, plot, and clean up |
| [Yanex](yanex.md) | Track exploratory runs and select result cohorts for comparisons |
| [Troubleshooting](troubleshooting.md) | Inspect failures without losing evidence |

Both workflows use the same data generator, translators, and execution functions.
They keep separate result stores. Start with the [quickstart](quickstart.md) if you
have not run the benchmark before.
